# Carry a relay-drafting brief into its repair without searching the replies

## Current behavior

When a relay-drafting reply cannot be read, the reply is stood upon and the ask
is made again with the same passage plus the unusable reply and the account of
what was wrong. The complaint carries only the offending reply and that account,
so the reaction that retries the ask has to find the passage again: it reads
every answered ask about the relay and keeps the one whose reply is exactly the
offering being complained about.

That read promises many rows. It answers one row for every ask about the relay
whose reply was that same text, so the retry is one ask per such row rather than
one ask outright. In practice the reasoner would have to return the identical
unusable reply to two different briefs about the same relay before a second
retry is asked, and the insistence's patience stops the second attempt anyway —
but nothing in the composition says so, and a reader cannot see the bound from
the reaction alone.

## Unresolved decision

Whether the complaint should carry what the next attempt needs — the passage it
stands on — so the retry reads nothing, or whether the composition should keep
searching the replies and the read should be given a promise that answers at
most one row.

## Acceptance condition

The retry names exactly one passage without a many-row read, and a relay whose
reasoner returns the same unusable text twice is shown to ask again exactly
once.
