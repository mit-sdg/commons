# Drafting the next round mid-run lands on an editor the page locks whole

## Current behavior

The run dashboard's "Draft a round" is a link to the relay's setup page with the
drafting panel open. That page greys out every round while the relay has an
open run, and says so in a banner. The composition refuses less: a round whose
questionnaire has an open run cannot be changed, but a round that has not run
can, and a new round can be added. So the drafting the design places on the
run page — describe the next round while this one is open, take the lines,
open it next — is possible at the edge and shut on the screen.

## Unresolved decision

Whether the setup page should lock only the rounds a run has reached, leaving
later rounds and the panel live, or whether the drafting panel belongs on the
run page as the design draws it, reading the relay and applying its lines
there while the setup page stays locked whole.

## Acceptance condition

With round one open, a staff member drafts round two from the run, takes its
lines, and opens it after closing round one, without leaving the run page or
being told that editing is locked.
