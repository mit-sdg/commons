# Decide what narrowing an assignment audience withdraws

## Current behavior

Widening a published assignment creates releases for newly covered learners.
Narrowing its targets leaves every existing release standing.

## Unresolved decision

Decide whether a narrower audience withdraws releases, preserves them as an
explicit exception, or asks staff to choose. Define the consequence for
existing submissions and grades.

## Acceptance condition

The assignment specification and application tests state what happens to each
affected release, submission, and grade when a published audience narrows.
