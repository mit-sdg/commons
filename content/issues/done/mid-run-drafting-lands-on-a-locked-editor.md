# Drafting the next round mid-run lands on an editor the page locks whole

## Resolution at completion

The setup page locks only the rounds the run has reached, each with the
sentence "Round N is in the run. It stays as it is."; later rounds, the
drafting panel, and adding a round stay live while a run is open. "Draft a
round" on the run dashboard opens that page with the panel open.

## Decision at completion

Drafting the next round mid-run happens on the setup page, one link from the
run, with the reached rounds locked one by one; the drafting panel is not
built into the run page. Recorded 2026-09-03 in the polish pass; the design
canvas's run-page panel is the shape a later step may still build.

## Verification at completion

With round one open, the setup page shows round one locked with its sentence
and round two editable; the drafting panel describes and applies lines for a
new round; after closing round one the new round opens from the run. The
class gate's and repair pass's tours walk this path in both themes.
